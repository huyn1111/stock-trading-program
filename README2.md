# 전략을 세우자!

1. 이동평균전략(Moving Average Crossover)
  * 5일 이동평균선 > 20일 이동평균선 : 매수
    5일 이동평균선 < 20일 이동평균선 : 매도
  * 가장 대표적인 추세추종전략
  * 장점 : 구현이 쉬움, parameter 튜닝 가능, 장기적으로 안정적
  * 단점 : 횡보장에서 손실 많음(whipsaw)

2. RSI 전략
  * 과매수/과매도 지표
  * RSI 값 범위 : 1 ~ 100
     - RSI < 30 : 너무 많이 떨어져있기 때문에 반등 가능 -> 매수
     - RSI > 30 : 너무 많이 올라가있기 때문에 하락 가능 -> 매도
  * 장점 : 반등 포착 가능, 단기 매매에 좋음
  * 단점 : 강한 상승장에서 계속해서 매도 신호 발생

3. 변동성 돌파 전략
  * 한국에서 자동매매할 때 가장 많이 쓰는 전략
  * 큰 변동성이 발생하면 추세가 시작된다!
  * 어제 변동성 = 어제 고가 - 어제 저가
  * 돌파가격 : 오늘 목표가 = 오늘 시가 + (어제 고가 - 어제 저가) * k (보통 k=0.5)
     - 현재가격 > 목표가겨 -> 매수
     - 당일 종가 매도 / 익절 +5%(매수가격보다 5% 오르면 매도) / 손절 -3%(매수가격보다 3% 떨어지면 매도) -> 매도전략
  * 장점 : 단순, 단타 자동매매에 좋음
  * 단점 : 횡보장에서 손실 가능

4. 스프레드 매매 - pvalue
  * 연관된 종목들 중에 하나가 오르면, 그것의 관계를 p value로 측정
  * 그리고 연관이 있는데 안오른게 있으면 매수

5. Momentum : 최근에 강한 자산은 앞으로도 강할 가능성이 높다.
  * 최근 상승률이 높은 종목을 사는 전략
  * N일 수익률을 계산해서 특정 일수동안 갖고있다가 매도하는 전략
    (주로 20일 수익률 측정해서 상위 20개 매수 후, 20일 보유 후에 매도)
